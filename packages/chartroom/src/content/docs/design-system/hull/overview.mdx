# @colis/hull <Badge text="v0.1.1" variant="note" />

`@colis/hull` is the design system and theming package for `@colis/keel`. It provides a three-layer CSS token architecture that assigns concrete visual values to the `--keel-*` CSS custom properties that keel components consume.

<Aside type="note" title="Current Status">
  Layer 1 token mapping and Layer 2 light/dark theme values are implemented and actively consumed by keel.
</Aside>

## Key Features

- **Three-layer architecture** — clean separation between base values, themes, and project overrides
- **Tailwind-first base layer** — battle-tested Tailwind token scale used as value source (Tailwind not required)
- **Built-in light/dark themes** — class-based or media-query dark mode
- **Project override mechanism** — apply your brand on top of hull without forking
- **Peer dependency on keel** — hull exists to theme keel, not standalone

## Dependency Rule

> **Keel works without hull. Hull requires keel.**

```bash
# keel only — works with built-in defaults
npm install @colis/keel

# keel + hull — full design system
npm install @colis/keel @colis/hull
```

## Three Layers at a Glance

| Layer | Location | Purpose |
|-------|----------|---------|
| Layer 1 — Base | `src/base/` | Tailwind-sourced values assigned to `--keel-*` tokens |
| Layer 2 — Themes | `src/themes/` | Light/dark and semantic variants |
| Layer 3 — Project | `src/project/` | Project brand override convention |
