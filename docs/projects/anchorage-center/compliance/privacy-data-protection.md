# Anchorage Center - Privacy & Data Protection

## Data Collected

- Email address
- Password hash (never plaintext)
- Session metadata (IP, user agent)
- Role and permission assignments

## Privacy Principles

- Data minimization
- Purpose limitation
- Least-privilege access
- Secure by default

## GDPR Requirements

- Right to access
- Right to deletion
- Right to data portability
- Consent management for email notifications

## CCPA Requirements

- Data disclosure upon request
- Opt-out for data sharing (not applicable for internal service)
- Deletion request handling

## Retention Policy (MVP Defaults)

- Sessions: purge on expiration
- Password reset tokens: 24 hours
- Email verification tokens: 30 days

## Data Deletion Workflow

- Verify requestor identity
- Delete user record and related sessions
- Log deletion event for audit trail

## Privacy Policy

- Maintain a published privacy policy
- Provide contact channel for data requests
