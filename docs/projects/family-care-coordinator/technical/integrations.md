# Technical: Integrations

## Notification Services
- Email provider for transactional reminders
- Push notifications via APNs and FCM

## Storage
- S3-compatible object storage for documents
- Antivirus scanning for uploaded files

## Calendar Sync (Post-MVP)
- Optional Google and Outlook calendar sync
- Two-way sync with conflict resolution rules

## Export and Sharing
- CSV/PDF exports for care summaries
- Shareable read-only links for emergency access (post-MVP)
