# Home Inventory Manager - Documentation Index

## Overview
Home Inventory Manager is a full-stack web and mobile application that helps users catalog household items, store photos and receipts, track warranties, and generate insurance-ready reports. It focuses on fast capture (barcode scanning and photos), organization by rooms and categories, and reliable access to item data during claims or moves.
