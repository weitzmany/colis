# Compliance: Accessibility

## Standards
- WCAG 2.1 AA baseline

## Requirements
- Keyboard navigation for all forms and actions
- Screen reader labels for form fields and buttons
- Minimum touch targets of 44x44px
- Color contrast ratio of 4.5:1 or higher

## Testing
- Manual keyboard walkthrough of key flows
- Screen reader checks for item creation and report download

## Review/Contribution

_Accessibility requirements cover core inventory and reporting flows._
