# Technical: Mobile Architecture

## MVP Strategy
- Mobile-responsive web app as the MVP
- PWA support for add-to-home-screen

## Phase 2 Strategy
- React Native app (iOS and Android)
- Offline access to tracking history
- Push notifications via Firebase Cloud Messaging

## Mobile UX Requirements
- Touch-friendly controls and spacing
- Load time under 3 seconds on 3G
- Core workflows available on small screens (>= 320px)
