# Introduction to Colis

The `@colis` ecosystem is a collection of packages that provide foundational tooling, UI components, and design systems for building web applications.

## What's in the ecosystem?

| Package | Purpose | Type |
|---------|---------|------|
| `@colis/keel` | Angular UI component library | UI Components |
| `@colis/hull` | Design system and theming | CSS/Design Tokens |
| `@colis/keel-mcp` | MCP server for AI assistants | Developer Tooling |
| `@colis/rig` | Development toolkit | Developer Tooling |
| `@colis/embark` | Project scaffolding | Developer Tooling |
| `@colis/logbook` | Git workflow management | Developer Tooling |
| `@colis/deck` | Task management | Developer Tooling |
| `@colis/shipyard` | Build and deployment | Developer Tooling |

## Where to start?

- **Building an Angular app?** → Start with [`@colis/keel`](/design-system/keel/overview/) for UI components.
- **Need theming/dark mode?** → Add [`@colis/hull`](/design-system/hull/overview/) for the full design system.
- **Using AI assistants in your project?** → Install [`@colis/keel-mcp`](/design-system/mcp/overview/) so your LLM always knows how to use keel/hull.
- **Starting a new project?** → Use [`@colis/embark`](/packages/embark/) to scaffold from templates.
- **Need port management or project setup tools?** → See [`@colis/rig`](/packages/rig/).
