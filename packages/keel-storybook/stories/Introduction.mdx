# @colis/keel Storybook

Welcome to the interactive component explorer for `@colis/keel` and `@colis/hull`.

- **Design Tokens** — explore all `--keel-*` CSS custom properties with live previews
- **Hull Themes** — see light/dark and semantic theme variants side by side

## Contributing Stories

When adding a new `@colis/keel` component:

1. Create `stories/components/<component-name>/<ComponentName>.stories.ts`
2. Document all `@Input()` props in `argTypes`
3. Add story variants for all visual states
4. Add the component to the theme matrix story in `stories/themes/ThemeMatrix.stories.ts`
5. Update `packages/keel-mcp/src/data/story-links.ts` with the new story IDs
