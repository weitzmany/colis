# Vehicle Maintenance Tracker - Documentation Index

## Overview

**Vehicle Maintenance Tracker** (AutoCare) is a customer-facing full-stack web and mobile application that helps drivers track vehicle maintenance schedules, service history, and total ownership costs.

**Target Users**: Car owners, families with multiple vehicles, used-car owners  
**Core Value**: Reduce unexpected repair costs through proactive maintenance tracking

## Key Features

1. **Maintenance Scheduler** - Recurring maintenance schedules with mileage-based reminders
2. **Service History** - Log services, repairs, invoices, and warranty info
3. **Expense Tracking** - Track fuel, insurance, repairs, and calculate total ownership costs
4. **Vehicle Profiles** - Manage multiple vehicles with VIN, mileage tracking
5. **Alerts & Notifications** - Upcoming service and warranty expiration reminders
6. **Reports & Export** - Maintenance history reports and expense summaries

## Tech Stack

- **Frontend**: Next.js (React) with TypeScript
- **Backend**: Node.js with Express or NestJS
- **Database**: PostgreSQL
- **Mobile**: React Native (iOS & Android)
- **Infrastructure**: Docker, CI/CD
