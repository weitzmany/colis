# New Project Command

Create a new customer-facing project using the same flow as "suggest new project".

## Workflow

1. Read criteria in `docs/reference/PROJECT_SELECTION_CRITERIA.md`.
2. Check `docs/reference/PROJECT_IDEAS_AVOID.md` to avoid banned ideas.
3. Propose a high-value customer-facing project (must include frontend, backend, mobile).
4. Create PRD at `docs/projects/<project-name>/PRD.md`.
5. Add the project to `docs/reference/PROJECTS_LIST.md` and update counts/summary.

## Output

- Short description of the project
- Why it is high value for customers
- PRD path confirmation

## Constraints

- Planning mode only (docs/.PLANNING_MODE is active)
- No developer-only tools; projects are for customers
- Avoid centralized infrastructure risks (per avoid list)
