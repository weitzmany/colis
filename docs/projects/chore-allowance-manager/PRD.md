# Chore & Allowance Manager - PRD

**Status**: Planning / Proposal  
**Last Updated**: 2026-01-05

## Project Name

**Chore & Allowance Manager** or **ChoreFlow**

## Project Type

Full-Stack Web & Mobile Application (Customer-Facing)

## Main Idea

A customer-facing app that helps families manage chores, rewards, and allowances. Parents can assign tasks, set rewards, and track completion. Kids can see their chores, earn points, and learn responsibility through clear, gamified progress.

## Target Audience

- Families with kids (ages 6–18)
- Parents managing household responsibilities
- Kids learning routines and accountability

## Technology Stack

**Frontend:**
- Next.js (React) with TypeScript
- Responsive design (mobile-first)

**Backend:**
- Node.js with Express or NestJS
- Database: PostgreSQL or MySQL

**Mobile:**
- React Native (iOS & Android)
- Push notifications for reminders

**Infrastructure:**
- Docker containerization
- CI/CD integration

## Core Features

### 1. Chore Assignment
- Create recurring chores
- Assign to family members
- Due dates and reminders

### 2. Rewards & Allowance
- Points or allowance per chore
- Bonus rewards for streaks
- Allowance history and totals

### 3. Family Dashboard
- Household overview
- Progress tracking per member
- Weekly completion summaries

### 4. Notifications
- Chore reminders
- Completion notifications
- Missed chore alerts

### 5. Gamification
- Streaks and badges
- Level‑up milestones
- Friendly progress charts

## Mobile App Features

### Core Mobile Features
- Quick chore check‑off
- Push reminders
- Offline access to chore lists

## Business Model

### Free Tier
- Up to 2 family members
- Basic chore tracking
- Limited rewards

### Premium Tier ($X/month)
- Unlimited family members
- Advanced rewards and analytics
- Priority support

## Success Metrics

- Weekly active families
- Chore completion rate
- 3‑month retention rate
- Average chores completed per user

## Development Phases

### Phase 1: MVP
- Chore lists and assignments
- Reminders
- Basic rewards

### Phase 2: Core Features
- Family dashboard
- Allowance tracking
- Mobile app

### Phase 3: Advanced Features
- Gamification
- Analytics and exports
- Multi‑household support
