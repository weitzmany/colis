# Compliance: Privacy and Data Protection

## Data Classification
- Personal data: account info, household details
- Sensitive data: item photos, receipts, valuations

## Privacy Requirements
- Provide data export and deletion
- Disclose storage and retention policy
- Obtain consent for photo and receipt storage

## Data Retention
- Soft delete items for 30 days
- Hard delete after retention window

## Access Controls
- Per-user data isolation
- Signed URLs for media access

## Compliance Targets
- GDPR-aligned data access and deletion
- CCPA-aligned data control

## Review/Contribution

_Privacy requirements align with sensitive household inventory data handling._
