# Home Maintenance Tracker - Documentation Index

## Overview

**Home Maintenance Tracker** (formerly "HomeCare") is a full-stack web and mobile application that helps homeowners and renters plan, track, and document home maintenance tasks and service history. The platform provides automated reminders, service history tracking, cost analysis, and helps prevent expensive repairs through proactive maintenance management.
