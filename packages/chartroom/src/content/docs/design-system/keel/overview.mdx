# @colis/keel <Badge text="v0.1.0" variant="note" />

`@colis/keel` is the Angular component library for the Colis ecosystem. It provides standalone Angular components (buttons, inputs, modals, and more) that projects can install and use immediately.

<Aside type="caution" title="Phase 1 — Foundation MVP">
  Phase 1 ships the installable package foundation and CSS token contract. Components are planned for Phase 2.
</Aside>

## Key Features

- **Standalone components** — Angular 17+ API, no NgModule needed
- **CSS token-based theming** — all styling via `--keel-*` CSS custom properties
- **Works without hull** — built-in fallback defaults for all tokens
- **Hull-compatible** — install `@colis/hull` to get a full design system
- **Zero runtime dependencies** on other `@colis` packages

## Installation

```bash
npm install @colis/keel
```
