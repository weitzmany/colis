# Technical: Observability

## Monitoring Tools
- Sentry for error tracking
- UptimeRobot for uptime
- Optional APM (Datadog/New Relic)

## Metrics
- API response times (p50/p95/p99)
- Carrier API success rate
- Email delivery rate
- Background job completion rate
- User retention and conversion

## Logging
- Structured JSON logs
- Centralized storage (Papertrail/Loggly/CloudWatch)

## Alerting
- Critical alerts for outages and API failures
- Warning alerts for degraded performance
