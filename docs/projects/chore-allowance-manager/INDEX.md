# Chore & Allowance Manager - Documentation Index

## Overview

**Chore & Allowance Manager** (ChoreFlow) is a customer-facing full-stack web and mobile application that helps families manage chores, rewards, and allowances. Parents can assign tasks, set rewards, and track completion. Kids can see their chores, earn points, and learn responsibility through clear, gamified progress.

**Target Audience**: Families with kids (ages 6–18)  
**Type**: Full-Stack Web + Mobile Application  
**Business Model**: Freemium (Free tier + Premium subscription)
