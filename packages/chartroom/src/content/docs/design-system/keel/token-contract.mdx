# CSS Token Contract

All `@colis/keel` components consume CSS custom properties (tokens) under the `--keel-{category}-{scale}` namespace. Every token has a built-in fallback so keel works without `@colis/hull`.

When `@colis/hull` is installed, it assigns the same variables with Tailwind-sourced values and theme-aware overrides.

:::note
For the complete shared contract spec, see `docs/reference/KEEL_HULL_TOKEN_CONTRACT.md` in the repository.
:::

## Overriding Tokens

You can override any token at `:root` level:

```css
:root {
  --keel-color-primary: #7c3aed;       /* brand purple */
  --keel-font-family: 'Geist', sans-serif;
  --keel-radius-md: 8px;
}
```

→ See [Project Theming](/design-system/hull/project-theming/) for the full Layer 3 pattern.
