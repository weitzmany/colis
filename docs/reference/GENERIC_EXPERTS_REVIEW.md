## Expert Persona Format Differences

### Games Project Format:
- **Detailed personas**: Names, ages, personalities, mottos, appearance
- **Project-specific context**: References specific tech stack (Angular, PHP, MySQL)
- **Comprehensive**: Very detailed with examples
- **23 expert files**: Extensive coverage

### Sandbox Project Format:
- **Simpler personas**: Less personality detail, more focused on behaviors
- **TaskMaster-focused**: References TaskMaster workflow
- **More concise**: Checklist-based, less verbose
- **15 agent files**: More focused set
